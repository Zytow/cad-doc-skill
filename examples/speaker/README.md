# Speaker example

A complete page made with the skill: `Speaker.md`, renders from `render/speaker.json`, the exploded drawing from `tools/callouts.py`, and the `context/` files that go with it.

The CAD model is not part of the repository, only the renders and the text. To reproduce the images, use your own STEP files and adapt `render/speaker.json` (part names, materials, explosion offsets).

Check the page: `python skills/cad-doc/scripts/check_page.py examples/speaker/Speaker.md --legacy`
